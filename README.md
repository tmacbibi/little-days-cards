# 人脈名片 (little-days-cards)

手機優先、低操作負擔的人脈管理 PWA。

## v0.7.0 — Simple People Manager

這一版的原則是：**少做一點，AI 多做一點。**
重點不再只是「把名片掃進來」，而是讓大量人脈更容易瀏覽、分類、健檢，並把免費 AI 流程盡量縮短。

### 這一版已完成

#### 1. 首頁更簡單
- 主入口改成「交給 AI 整理」
- 明確標示：
  - 預設免費
  - 目前推薦 Claude
- 快速新增仍保留
- 備份狀態不再佔首頁主要空間，移到更多功能裡

#### 2. 免費 AI 流程簡化
目前不呼叫付費 API。

流程變成：
1. 加入照片 / PDF / Excel / CSV / vCard / JSON
2. 按「分享給 AI 整理」
3. 在 iPhone 分享選單選 Claude 或其他可用 AI App
4. AI 依 Little Days 格式回傳 JSON
5. 在 AI App 複製結果
6. 回到 Little Days 按一次「從剪貼簿直接回填」

不再要求：
- 下載 JSON
- 找 JSON 檔
- 再重新匯入

只有 iOS 不允許讀剪貼簿時，才展開手動貼上作為 fallback。

#### 3. AI 結果回填
單一人物：
- 直接回填姓名
- 公司
- 部門
- 職稱
- 手機
- 公司電話
- Email
- 地址
- 網站
- 認識場合
- 專案
- 備註
- 標籤
- AI 建議確認欄位

多位人物：
- 進批次預覽
- 自動去重
- 標記 AI 待確認項目
- 可批次加入資料庫

AI 來源不再寫死 ChatGPT，支援 Claude 或其他 AI App。

#### 4. 人脈列表改版
參考成熟名片管理工具的人脈瀏覽方式，但保留 Little Days 自己的視覺：
- 名片縮圖
- 姓名
- 公司
- 職稱
- 最愛
- 追蹤
- 最近互動
- AI 待確認提示
- 右側英文字母索引（有英文姓名時顯示）

#### 5. 人脈分類
新增「人脈分類」：
- 依公司 / 機關
- 依標籤
- 依 AI / 衍生分類
- 一個人可以同時屬於多個分類
- 顯示每個分類的人數
- 點一下立即篩選整個人脈列表

#### 6. AI 人脈健檢
新增「人脈健檢」：
- AI 待確認
- 疑似重複
- 資料不完整
- 超過一年未互動 / 更新

原則是：
**不要叫使用者整理全部，只列出例外。**

#### 7. 新增入口簡化
按「＋」後改成簡單清單：
- 交給 AI 整理
- 拍照暫存
- 匯入既有資料
- 手動快速新增

不再用太多大型功能卡片。

#### 8. 檔案匯入保留
- CSV
- Excel
- vCard
- JSON
- 圖片
- PDF 來源辨識
- 智慧欄位對應
- 去重
- 批次匯入
- 批次復原

需要真正視覺理解的照片 / PDF，優先建議走「交給 AI 整理」。

#### 9. 原有功能保留
- Capture Inbox
- 本機 OCR fallback
- 快速搜尋
- 標籤
- 最愛
- 待追蹤
- 互動時間軸
- 我的數位名片
- vCard 分享
- 完整 JSON 備份 / 恢復
- 匯入批次歷史
- CSV 匯出
- PWA 離線核心資料存取

### 費用原則

v0.7 預設仍然不呼叫 OpenAI API。

如果使用者點「全自動 API 模式」：
- 先顯示明顯費用警示
- 必須主動勾選「知道 API 可能另外收費」
- 目前仍不會真正呼叫 API
- 真正建立 API 後端前，仍不會產生 API 使用費
