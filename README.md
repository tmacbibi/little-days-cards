# 人脈名片 (little-days-cards)

手機優先、低操作負擔的人脈管理 PWA。

## v0.8.0 — Little Days UI Polish

這一版以「更清楚、更大字、更少誤操作」為重點，維持 Little Days 的柔和、簡潔風格。

### 本版完成

- 全站文字尺寸放大、對比加強
- 首頁資訊層級更清楚
- 人脈列表姓名、公司、職稱更容易閱讀
- 聯絡人縮圖統一只顯示姓名第一個字
- 名片照片縮圖取消姓名 alt 文字，避免圖片載入異常時文字跑出縮圖框
- AI 人脈助理重新分區：
  - 「智慧處理方案」：標準智慧模式 / 進階自動化模式
  - 「AI 整理流程」：STEP 1 / STEP 2 / STEP 3
  - 「整理結果回填」
- 免費模式與 API 模式改成同一階層的雙卡片設計
- 三個操作步驟改成大型 STEP 1 / 2 / 3 視覺
- 三大區塊使用較粗框線分隔，避免功能層級混在一起
- 名稱改得更專業：
  - 免費模式 → 標準智慧模式
  - 全自動 API 模式 → 進階自動化模式
  - 三步就好 → AI 整理流程
  - 想補充什麼 → 情境補充
- 剪貼簿回填仍為免費模式主要流程
- 付費 API 仍未啟用，預設不會產生 API 費用

### 目前主要流程

1. STEP 1 加入資料
2. STEP 2 分享給 AI
3. STEP 3 複製結果並一鍵回填

### 原有功能保留

- AI 免費橋接流程
- Claude / 其他可分享 AI App
- 檔案匯入
- 人脈分類
- AI 人脈健檢
- 待追蹤 / 最愛 / 搜尋
- 互動紀錄
- 備份與恢復
- PWA 離線核心功能
