# 人脈名片 (little-days-cards)

手機優先的 PWA 名片管理工具。

## v0.2.0
- 名片新增／編輯／刪除
- iPhone 相機或相簿加入名片照片，前端壓縮後儲存
- IndexedDB 本機資料庫
- 姓名、公司、職稱、專案、場合、標籤、備註全文搜尋
- 最愛／待追蹤／最近新增篩選
- 電話、Email、Apple Maps 快捷操作
- vCard 分享
- JSON 完整備份／恢復
- CSV 匯出
- PWA 離線快取與 iOS 主畫面安裝

## 下一版
