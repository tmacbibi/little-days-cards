# 人脈名片 (little-days-cards)

手機優先、關係導向的 PWA 名片管理工具。

## v0.4.0 — Capture & Memory

這一版把核心流程改成「先收進來，再整理」：拿到很多名片時，不必站在掃描頁等 OCR 跑完。

### Capture Inbox
- 拍照後先立即保存到「待整理名片」
- 支援連續掃描：拍完一張可直接拍下一張
- 相簿可一次加入多張照片
- App 開著時依序背景整理；中途關閉也不會丟失，下次打開續跑
- 輕量自動裁切
- OCR 完成後再點進去快速確認姓名、公司、電話、Email
- 確認儲存後自動離開待整理匣

### 快速新增與人脈記憶
- 姓名、公司、手機、Email 為主要快速欄位
- 其他資料收在「更多資料」
- 語音補備註
- 重複人脈偵測與合併
- vCard (.vcf) 匯入
- 搜尋姓名、公司、職稱、專案、場合、標籤、備註與互動紀錄
- 最愛／待追蹤／最近新增
- 每位聯絡人的互動時間軸與下次追蹤
- 產生行事曆事件 (.ics)

### 備份與資料安全
- IndexedDB 本機資料庫
- 完整 JSON 備份包含：
  - 人脈資料
  - 名片照片
  - 互動紀錄
  - 待整理名片
  - 我的數位名片
  - App 設定
- 備份檔含 schema version，供未來版本遷移
- iPhone 分享表可直接存到「檔案 / iCloud Drive」或 Google Drive
- 顯示上次備份時間與備份筆數
- 合併恢復：保留現有資料並合併
- 整份取代：先自動建立一份「恢復前備份」，再取代目前資料
- CSV 匯出
- App 更新不清空 IndexedDB

### 我的數位名片
- 個人數位名片
- QR Code
- vCard 一鍵分享
- Apple Wallet 介面預留（正式 .pkpass 仍需 Apple 憑證與簽章後端）

## 限制

PWA 無法像原生 iOS App 一樣在 App 完全關閉後持續做真正背景 OCR。因此 v0.4 的策略是：照片先安全落地到 Capture Inbox，App 開著時再背景整理；離開後下次開啟會續跑。
